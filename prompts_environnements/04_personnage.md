# 4. Personnage — l'enfant (en harmonie avec le jardin)

Enregistre les images dans resultats/ : enfant_reference.png puis enfant_sprites.png

## Prompt A — Fiche de référence (à faire en premier)

```
STYLE (keep identical for every image): high-quality top-down 3/4 view pixel art for a 2D adventure game, like classic Zelda or Stardew Valley camera angle. Miniature world seen at the scale of an ant: everyday garden things are gigantic. Cinematic, warm and magical mood inspired by macro nature photography and whimsical miniature-world fantasy films: rich saturated greens and earthy browns, soft golden rim light, light always coming from the top-left, gentle soft shadows falling to the bottom-right, clean dark outlines on objects, limited cohesive palette, crisp pixels, no blur, no anti-aliasing smear, no photorealism.

CONTENT: a character reference sheet of the hero, shown 4 times side by side in a single row: facing down (front), facing up (back), facing left, facing right. Same character, same size, same colors in all 4 views, standing idle, full body, centered, generous empty space around each view.
The hero: a cheerful 8-year-old Black boy, dark brown skin, round friendly face, big expressive eyes, short black curly afro hair, NO beard and NO facial hair (he is a child), bright mustard-yellow t-shirt with a small round leaf badge on the chest, blue shorts, white sneakers with green laces, a small brown leather satchel on the side, a wooden Y-shaped slingshot tucked in his belt. Slightly big head and chibi proportions (head about one third of body height) so he reads well when small. Warm golden rim light from top-left matching the garden scenes.
Solid flat pure magenta background (#FF00FF) everywhere, only a tiny soft contact shadow under the feet.

STRICTLY AVOID: any text, letters, numbers, labels, watermarks, UI, frames, borders, grid lines, other characters, insects, scenery, background objects, beard, mustache, adult proportions, side-scroller view, isometric, blurry or painterly areas.
```

## Prompt B — Planche d'animations (avec l'image A jointe comme référence)

```
Use the attached character as the exact reference: same boy, same face, same hair, same clothes, same colors, same pixel art style.

STYLE: high-quality top-down 3/4 view pixel art for a 2D adventure game (Zelda / Stardew Valley camera angle), warm golden light from the top-left, clean dark outline, crisp pixels, no blur.

CONTENT: a sprite sheet of this boy on a solid flat pure magenta background (#FF00FF). Strict invisible grid: 6 columns, 8 rows, every cell the same square size, the character centered in each cell with the same scale and feet on the same baseline, cells never overlap, nothing crosses into another cell.
Row 1: idle facing down, 6 frames (gentle breathing).
Row 2: idle facing up, 6 frames.
Row 3: walk facing down, 6 frames.
Row 4: walk facing up, 6 frames.
Row 5: walk facing right, 6 frames (side view of the same top-down 3/4 character).
Row 6: shoot the slingshot facing down: pull the band back, aim, release, a small golden seed flies out, return to idle, 6 frames.
Row 7: shoot the slingshot facing right, same 6 steps.
Row 8: 3 frames hurt (flinch, eyes closed) then 3 frames victory (jumping, arms up, happy).
Left-facing frames are not needed (they will be mirrored).

STRICTLY AVOID: any text, letters, numbers, labels, watermarks, UI, frames, borders, grid lines drawn on the image, scenery, other characters, changes of outfit or face between frames, beard or facial hair, size changes between frames, blur.
```
